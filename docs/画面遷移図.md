# 画面遷移図

画面ID（S01〜S50）は [spec.md](../spec.md) の「63. プロトタイプの画面構成」に合わせています。
各節の画像は、主な画面のスクリーンショットをつないだ図です。点線の枠は、スクリーンショットをまだ載せていない画面です。
「テキスト版の図」を開くと、画像では省いた補足の画面（食材の修正など）も含めた遷移を見られます。

画面上部のメニュー（ホーム・食材・レシピ・商品）からは、どの画面からでもそれぞれの一覧へ移動できます。図ではこの移動を省いています。

```mermaid
  S02 -->|食材を登録する| S11[S11 食材登録]

  S02 -->|商品原価を見る| S30[S30 商品原価一覧]

  S02 -->|上部メニュー| S20[S20 レシピ一覧]
  S02 -->|管理者メニュー| S50([S50 管理画面])
  S02 -.->|探す（横断検索）| DETAIL[S14 食材詳細<br/>S24 レシピ詳細<br/>S31 商品詳細]

  classDef todo stroke-dasharray: 5 5
  class S01,S50 todo
```

</details>

![食材の画面遷移](images/画面遷移図/flow-2-ingredients.png)

<details>
<summary>テキスト版の図（補足の画面も含む）</summary>

```mermaid
flowchart TB
  S10[S10 食材一覧] -->|食材を登録する| S11[S11 食材登録 入力]
  S10 -->|食材を選ぶ| S14[S14 食材詳細]
  S11 -->|登録する| S12[S12 登録内容の確認]
  S12 -->|戻って修正する| S11
  S12 -->|この内容で登録する| REG[S12 登録完了]
  REG -->|アレルゲンを今入力する| S13[S13 アレルゲン入力]
  REG -->|あとで入力する| S14
  REG -->|栄養成分を入力する| NUT[栄養成分入力]
  REG -->|続けて別の食材を登録する| S11
  S13 -->|確認済みにする / やめる| S14
  S14 -->|アレルゲンを修正する| S13
  S14 -->|栄養成分 入力する / 修正する| NUT
  NUT -->|保存する / やめる| S14
  S14 -->|修正する| EDIT[食材の修正]
  EDIT --> S14
  S14 -->|価格を変更する| S41[S41 新しい価格を入力]
  S14 -->|使っているレシピ・商品| OTHER[S24 レシピ詳細<br/>S31 商品詳細]

  classDef todo stroke-dasharray: 5 5
  class EDIT todo
```

</details>

S11 では、一覧にない仕入先をその場で登録できます（画面は移動しません）。

## 価格変更

![価格変更の画面遷移](images/画面遷移図/flow-3-pricing.png)

<details>
<summary>テキスト版の図（補足の画面も含む）</summary>

```mermaid
flowchart LR
  S40[S40 食材を選ぶ] -->|食材を選ぶ| S41[S41 新しい価格を入力]
  S41 -->|食材を選び直す| S40
  S41 -->|影響を確認する| S42[S42 影響確認]
  S42 -->|戻って修正する| S41
  S42 -->|この価格に変更する| S14[S14 食材詳細]
```

</details>

S14 食材詳細の「価格を変更する」からは、S40 を飛ばして S41 から始まります。

## レシピ

![レシピの画面遷移](images/画面遷移図/flow-4-recipes.png)

<details>
<summary>テキスト版の図（補足の画面も含む）</summary>

```mermaid
flowchart TB
  S20[S20 レシピ一覧] -->|レシピを作る| S21[S21 レシピを作る]
  S20 -->|レシピを選ぶ| S24[S24 レシピ詳細]
  S20 -->|中間レシピの置き換え| S25[S25 中間レシピの置き換え]
  S21 -->|作って材料を追加する| S22[S22 レシピ編集]
  S24 -->|工程・並び順| S22
  S24 -->|新しいバージョンを作る| S22
  S24 -->|コピーして作る| S21
  S24 -->|作り方 修正する| INFO[名前・作り方の修正]
  S24 -->|このレシピを別のバージョンに置き換える| S25
  S24 -->|このレシピで商品を登録する| S32[S32 商品登録]
  S24 -->|材料・使っているもの| OTHER[S14 食材詳細<br/>S24 中間レシピの詳細<br/>S31 商品詳細]
  S22 -->|材料を追加する| S23[S23 材料検索<br/>編集画面内のパネル]
  S23 -->|レシピに追加 / 閉じる| S22
  S22 -->|名前・手順・メモ| INFO
  INFO -->|保存する / やめる| S24
  INFO -.->|編集画面から開いたとき| S22
  S22 -->|← レシピ詳細| S24
  S25 -->|この内容で置き換える| S25D[置き換え完了]
  S25D -->|新しいバージョンを見る| S24

  classDef todo stroke-dasharray: 5 5
  class S23,S25,S25D todo
```

</details>

使用中のレシピは、S22 で材料・使用量を変えられません（工程と並び順は変えられます）。材料を変えるときは「新しいバージョンを作る」で新しいバージョンを作ります。
