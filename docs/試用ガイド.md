# 試用ガイド

パン・食品製造向け「レシピ・原価・食材・販売価格管理アプリ」のプロトタイプを試すための手順です。
試用データ（仕入先・価格はすべて架空）が入っています。スマートフォンとPCのどちらでも使えます。

## 1. 開く

1. 案内と一緒に受け取った URL（`https://〜-8000.app.github.dev`）をブラウザで開く
2. 次のユーザーでログインする

| ユーザー名 | パスワード | 権限 |
|---|---|---|
| `demo_admin` | `demo-bakery-2026` | 管理者（食材の登録・商品の登録・使用停止などすべて） |
| `demo_staff` | `demo-bakery-2026` | 一般（閲覧、レシピの作成・編集、食材価格の変更、写真） |

- 必要なのはブラウザだけです。アプリのインストールや、GitHub のアカウントは要りません
- 使えるのは、案内された時間帯だけです。ページが開けないときは、URL を送った人に連絡してください

## 2. 試してほしいこと

**原価を見る**
- ホーム →「商品原価を見る」：バゲット・バターロール・クリームパンの原価・原価率
- 商品を開く：原価の内訳、アレルゲンとその由来、栄養成分表示（1個当たり・推定値）

**レシピを作る**
- ホーム →「レシピを作る」→ 新しく作る → 中間レシピ（例：生地）
- 「＋ 材料を追加する」で食材や中間レシピを検索して追加。画面下の原価が即時に変わる
- 「≡」をつかんで並べ替え（スマートフォンは長押し）、「材料ごとに合計」への切り替え

**価格を変える**
- ホーム →「価格を変更する」→ 例：強力粉を 5,200円 → 6,000円
- 確定前に、影響する商品ごとの原価・原価率の変化が見られる

**使用中のレシピを変える**
- 「バターロール生地」を開く → 使用中なので材料は直接変えられない →「新しいバージョンを作る」
- 管理者で「中間レシピの置き換え」を使うと、影響確認のうえ上位レシピへ一括で反映できる

**写真**
- レシピ詳細・商品詳細の右上の「□＋」から写真を追加（スマートフォンでは撮影もできる）

**栄養成分**
- 管理者で食材を開く →「栄養成分（100gあたり）」→ 日本食品標準成分表から選ぶ

## 3. 感想を送る

気づいたこと（分かりにくい画面・言葉、足りない機能、計算の違和感など）は、URL を送った人に伝えてください。
どの画面で、何をしたときのことかを添えてもらえると助かります（スクリーンショットがあれば、なお助かります）。

## 注意

- これは試用のためのプロトタイプです。実際の業務データは入れないでください
- 試用する人は全員、同じデータを使います。登録・変更した内容や写真は、ほかの人にも見えます
  （価格を変えると、ほかの人が見る原価も変わります）
- 表示される栄養成分は推定値です
- 栄養値の出典：日本食品標準成分表（八訂）増補2023年（文部科学省）を加工して作成
